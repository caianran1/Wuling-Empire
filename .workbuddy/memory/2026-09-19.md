## 重大口径修正：「凝聚」= 生成实体实物（0.2.4）
用户明确纠正：**「凝聚是凝聚出实体武灵，凝聚不是开启（界面）」**——之前把凝聚做成了「打开选择界面 + 写玩家数据」，方向错了。
现改为：**凝聚 = 在世界上生成一件实物**，由「武灵种类 + 当前境界」决定它是什么。
- `WuLingType.manifest(realmOrdinal, stageOrdinal)`：新增。按种类+境界返回 `ItemStack`：
  剑→木/石/铁/金/钻石/下界合金剑；斧、镐、铲、盔甲同理（`mapTier`）；
  弓→`BOW` 附 `POWER_ARROWS`（绿宝石境界再附 `INFINITY_ARROWS`）；水→水桶、火→烈焰棒、红石→红石、书→附魔书（附 `UNBREAKING`）。
  自定义名 `wuling.manifest.name` = `%1$s%2$s武灵`（如「钻石剑武灵」）。
- `WuLingBinding` 拆成两个语义清晰的方法：
  - `bind(player, typeKey, creative)`：**选种类并绑定**（绑定器 Shift+右键 / 创造绑定器 打开界面后选中）。创造模式绑定后立即 `condense` 一次。
  - `condense(player)`：**凝聚出实体实物**——取 `data.type().manifest(data.realmOrdinal(), data.stageOrdinal())`，
    在玩家位置 `y+1` 生成 `ItemEntity`（`setPickUpDelay(0)`），播 `PLAYER_LEVELUP`，提示 `condense_success`。
    前置：已绑定 + 背包内有绑定器（普通或创造）。
- `WuLingCondensePacket` 重构为带 `action`（`bind` / `condense`）的通用包：`new WuLingCondensePacket()` = 凝聚；`new WuLingCondensePacket(typeKey, creative)` = 绑定。
- `ClientTickHandler`：**Shift+M 只发包凝聚，不再开界面**。
- 新语言键：`message.wulingdiguo.condense_success`、`condense_need_bind`、`condense_need_shift`、`wuling.manifest.name`（zh_cn + en_us 均已补）。
- 构建：版本升 `0.2.4`，`BUILD SUCCESSFUL in 1m 30s`（20:24）。
  产出 `build\libs\wulingdiguo-0.2.4.jar`（113,605 B）。已解包核对：5 个关键 class 齐全、zh_cn 含 `condense_success` 等新键。
